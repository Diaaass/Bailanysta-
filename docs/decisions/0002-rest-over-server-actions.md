# 0002. REST-роуты, а не только Server Actions

## Контекст

Next.js предлагает Server Actions — мутации вызываются как обычные функции, без
ручного описания HTTP-слоя. Кода получается заметно меньше.

## Решение

Мутации и чтение идут через route handlers под `/api/*`. Server Actions
используются только там, где HTTP-контракт наружу не нужен — например, выход из
аккаунта.

## Последствия

**Хорошее.** Бэкенд видно и можно позвать: `curl` проверяет поведение без
браузера, контракт можно показать. Именно так во время разработки проверялись
коды ответов, валидация и права доступа. Если появится второй клиент, API уже
готов.

**Плохое.** Больше кода: на каждую операцию — разбор тела, валидация, коды
ответов. Часть этого Server Actions делают сами.

**Чего это стоило.** Одиннадцать файлов роутов вместо нескольких серверных
функций.
