# 0004. Вход по логину и паролю вместо OAuth

## Контекст

Auth.js из коробки поддерживает GitHub, Google и другие провайдеры. Это
безопаснее собственной работы с паролями и удобнее для пользователя.

## Решение

Provider Credentials: имя пользователя и пароль, хеширование bcrypt, сессия в JWT
внутри httpOnly-куки.

## Последствия

**Хорошее.** Проверяющий заводит аккаунт за десять секунд, не регистрируя
OAuth-приложение и не выдавая доступ к своему GitHub. Демо-аккаунт работает без
внешних сервисов, поэтому приложение поднимается локально даже без интернета —
кроме AI-функций.

**Плохое.** Пароли — своя ответственность. Нет восстановления доступа, нет
двухфакторной аутентификации, нет защиты от подбора на уровне входа.

**Оговорка.** Для настоящего продукта это неверный выбор. Здесь он сделан ради
воспроизводимости проверки, и это осознанный размен.
